# Chatcode issues and feature requests

This is the public feedback tracker for [Chatcode](https://chatcode.dev).
Anyone can browse issues. Sign in to GitHub to report a bug, request a feature,
comment, or add a reaction. Access to Chatcode's source repository is not required.

- [Browse issues](https://github.com/chatcode-lab/feedback/issues)
- [Report a bug or request a feature](https://github.com/chatcode-lab/feedback/issues/new/choose)

Before opening an issue, search for an existing report. If someone has already
raised the same problem or request, add a thumbs-up reaction or useful details
to that issue. Include steps to reproduce bugs and explain the problem a proposed
feature would solve.

Issues and attachments are public. Remove credentials, private code, and personal
data from anything you post. For account-specific help, use **Ask support** in
Chatcode or email [help@chatcode.dev](mailto:help@chatcode.dev). Report security
vulnerabilities privately using the [security policy](SECURITY.md).

Be respectful and keep each issue focused on one topic. Maintainers use labels
and comments to share progress; an open issue does not promise a delivery date.

This repository contains community documentation and issue forms only. Product
development remains in Chatcode's separate source repository.
